# 🚀 Placement Management System

A modern **Full-Stack MERN Placement Management System** developed to streamline the campus recruitment process through dedicated dashboards for **Students** and **Administrators**. The application provides a secure, intuitive, and responsive platform for managing placements, company recruitment drives, and student applications efficiently.

# ✨ Key Features

### 🔐 Authentication & Security

* Secure Login & Registration
* JWT-based Authentication
* Password Encryption
* Protected Routes
* Role-Based Access Control

### 👨‍🎓 Student Module

* Student Dashboard
* Personal Profile Management
* Browse Available Companies
* View Company Details
* Apply for Job Opportunities
* Track Application Status
* View Applied Companies
* Update Profile Information
* Responsive User Experience

### 👨‍💼 Admin Module

* Admin Dashboard
* Company Management
* Add New Companies
* Edit Company Information

* Publish Placement Opportunities
* Manage Student Applications

* Monitor Placement Activities
* Full CRUD Functionality

* Interactive Dashboard
